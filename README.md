WiFi 指纹室内语音导航安卓应用
 
纯离线运行、面向视障用户的校园室内导航安卓应用。
依托本地 WiFi 指纹定位、手机传感器步航推算、离线语音识别与语音播报，实现无网络、无蓝牙硬件辅助的室内自主定位与步行导航，专为室内无 GPS 场景下的视障人群独立出行设计。
 
项目特点
 
- 完全离线：定位、地图、语音识别、语音播报全部本地运行，无需联网
- 无硬件依赖：无需部署蓝牙 Beacon、室内定位基站，仅依赖手机自带 WiFi、陀螺仪、加速度计、麦克风
- 无障碍适配：全语音操控、手势操作、多模态反馈，适配视障用户使用习惯
- 低延迟实时导航：WiFi 粗定位 + 传感器精跟踪，修正行走漂移误差
 
技术栈
 
- 平台：Android 6.0 ~ Android 14（SDK23–34）
- 开发工具：Android Gradle 8.1.0、Gradle 8.13、Java 17
- 本地数据库：Room（存储 WiFi 指纹、位置点位）
- 定位算法：KNN 近邻匹配算法
- 路径算法：BFS 广度优先最短路径搜索
- 离线语音：Vosk 离线语音识别、自定义优先级 TTS 语音播报
- 传感器：罗盘、加速度计实现行人航位推算(PDR)
 
整体架构
 
项目采用分层服务架构，单 Activity 设计，模块解耦清晰：
 
1. 全局管理层
 
-  App ：程序入口，初始化地图数据、WiFi 指纹数据库
-  AppStateManager ：全局状态机，管控空闲、定位中、导航中、语音监听四种状态，防止任务冲突
-  ServiceFactory ：统一创建、管理所有业务服务实例
 
2. UI交互层
 
- 单页面主界面，全手势操作
- 自定义呼吸状态视图，直观展示运行状态
- 适配系统屏幕阅读器，无障碍界面兼容
- 内置悬浮设置面板，支持语速、多语言切换
 
3. 离线语音交互层
 
整套本地语音闭环，支持免手操作：
 
- 离线语音识别：解析用户自然语言指令
- 本地语义引擎：识别定位、导航、紧急求助、设置调节指令
- 优先级语音播报：导航指令优先播报，支持去重防抖动
- 自动回声抑制：播报时暂停收音，避免自识别干扰
 
4. WiFi 室内定位层
 
- 周期性扫描周边 WiFi BSSID、RSSI 信号强度
- 过滤弱信号数据，提升定位稳定性
- KNN 算法比对本地预存 WiFi 指纹库，匹配最优室内位置点位
- 全本地数据库比对，无网络请求
 
5. 室内导航引擎层
 
- 解析本地 JSON 室内拓扑地图
- BFS 计算楼层内、跨楼层最短步行路径
- 传感器融合：罗盘定向 + 加速度计计步实现连续行走跟踪
- 周期性 WiFi 定位校正，消除 PDR 行走累计误差
- 实时语音逐段指引转向、前进、楼层切换
 
核心功能
 
1. 离线室内定位
基于校园预设 WiFi 指纹地图，实时获取用户室内精确位置。
2. 语音免手导航
支持语音输入目的地，自动规划路径并全程语音引导行走。
3. 实时步行跟踪
通过手机传感器持续追踪用户行走状态，动态匹配路线进度。
4. 多模态反馈
语音播报、屏幕状态动画、振动反馈结合，适配视障用户感知方式。
5. 离线多语言支持
内置中文、英文、粤语语音识别与播报切换。
6. 紧急求助功能
一键/语音触发紧急状态，播报当前室内位置信息。
 
项目运行环境
 
- 编译要求：Java 17、Android NDK、Gradle 8.13
- 兼容设备：Android 6.0 及以上
- 必需权限：WiFi 扫描、位置权限、麦克风、振动、屏幕常亮
- 必需硬件：WiFi 模块、麦克风、惯性传感器
 
启动流程
 
1. 应用初始化，加载本地室内地图拓扑数据
2. 自动导入预存 WiFi 指纹数据至本地数据库
3. 初始化语音、定位、导航所有服务
4. 校验设备权限，进入主交互界面
5. 支持手势/语音启动定位与导航任务
 
适用场景
 
主要用于大型室内校园建筑，解决 GPS 失效、无专用定位硬件环境下，视障用户室内自主行走、找教室、找电梯、楼层穿梭的独立导航需求。
 
项目优势总结
 
纯离线、零服务端、零部署硬件、完全本地化计算，是一套轻量化、可直接部署落地的安卓端室内无障碍导航完整解决方案。
